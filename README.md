
# Modern Periodic Table - Console Application  
🔬 **Explore the Elements of the Periodic Table Using C**  

---

## 🚀 Overview  
This console-based application is a modern and interactive way to explore the periodic table of elements. Built using **C programming**, it provides users with easy access to essential information about each element. The application emphasizes efficiency and a user-friendly console interface.  

---

## ✨ Key Features  
- **Search by Element Name or Symbol:** Quickly retrieve details about any element.  
- **Element Information:** Displays atomic number, symbol, atomic mass, and more.  
- **Interactive Console UI:** Simple and intuitive navigation.  
- **Error Handling:** Robust checks for invalid input to ensure smooth operation.  

---

## 🛠️ Technologies Used  
- **Programming Language:** C

## 🖥️ How to Run  

### Prerequisites  
- **C Compiler:** Ensure GCC or any standard C compiler is installed.  

### Steps to Run Locally  
1. Clone the repository:  
   ```bash
   git clone https://github.com/jawahar05900/modern-periodictab_console_c.git
   cd modern-periodictab_console_c
   ```  
2. Compile the program:  
   ```bash
   make
   ```  
3. Run the application:  
   ```bash
   ./modern_periodictab
   ```
